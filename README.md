# Homebrew Tap for EasyClipboard

Official Homebrew tap for **[EasyClipboard](https://easyclipboard.app)** — the most flexible visual clipboard manager for macOS.

## Installation

Install directly with a single command (automatically removes macOS quarantine flags so it opens immediately without Gatekeeper prompts):

```bash
brew install --cask ademkivanc/tap/easyclipboard
```

Or tap first and then install:

```bash
brew tap ademkivanc/tap
brew install --cask easyclipboard
```

## Updating

```bash
brew upgrade --cask easyclipboard
```

## Uninstalling

```bash
brew uninstall --cask easyclipboard
```
